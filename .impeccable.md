# Impeccable — Design Context

## Design Context

### Users
A single company trader (restricted UCITS ETF universe) using a private research
dashboard. Context is deliberate and low-frequency: a monthly manual rebalance
plus occasional strategy/validation review. Never a public product. The user
reads numbers, judges risk, and enters orders by hand elsewhere — the dashboard
informs a decision, it never executes one.

Jobs to be done: scan strategy/backtest results, inspect validation & overfitting
evidence, watch live risk, and produce rebalance recommendations — with enough
in-page guidance that a page read cold still makes sense.

### Brand Personality
Calm confidence. Quiet, trustworthy, data-first. Nothing shouts; the interface
recedes so the numbers lead. Three words: **precise, composed, honest.**
Emotional goal: the user trusts what they see and moves on quickly.

### Aesthetic Direction
Flat document layout (no floating hero container), light mode only. Indigo-tinted
neutral palette driven by CSS variables in `scripts/server/static/shared.css`
(`--ink`, `--paper`, `--accent` #3d4ca8, semantic `--good`/`--warn`/`--bad`).
Editorial/technical restraint over decoration.

**Anti-references (must NOT look like):**
- Cluttered legacy broker UI — no cramped tables, tiny fonts, gray-on-gray.
- Consumer fintech (Robinhood-ish) — no playful confetti, oversized rounded shapes.
- Generic SaaS card grids — no endless identical cards, no hero-metric template.
- (Also never: crypto/neon, dark+glow, purple→blue gradients, gradient text.)

### Design Principles
1. **Numbers lead, chrome recedes.** Typography and spacing carry hierarchy;
   containers and borders are minimal. Flat over floating.
2. **Guidance everywhere.** Every page teaches itself — labels, empty states,
   and short explainers so a cold read still makes sense.
3. **Honest semantics.** Good/warn/bad color is reserved for real signal, never
   decoration. Do not dress up weak results.
4. **Vary the rhythm, not the system.** Break the identical-card grid with
   intentional spacing and layout, but stay inside the shared.css token system.
5. **Calm, not clinical.** Composed and precise without becoming a cramped
   terminal — generous line-height and breathing room.

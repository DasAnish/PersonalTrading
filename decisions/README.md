# decisions/

Architecture Decision Records (ADRs) — durable notes on *why* a significant design choice was made, so it isn't re-litigated later.

One dated markdown file per decision, e.g. `strategy_architecture_2026-03-13.md` (the composable AssetStrategy / AllocationStrategy / OverlayStrategy design).

Add a new file when making a non-obvious architectural call; don't edit old ones — supersede them with a new dated record.

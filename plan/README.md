# plan/

Active GSD (Get Stuff Done) plan for the current body of work — milestones broken into phase files.

- `index.md` — plan overview and phase list
- `state.md` — the state tracker; which phase/TODO is current (read by `/continueplan`)
- `phase-NN-*.md` — one file per phase, from dead-code cleanup through pipeline wiring and the validation battery

Managed by the GSD skills (`/clearplan`, `/newplan`, `/continueplan`). See [../docs/gsd-planning.md](../docs/gsd-planning.md).
